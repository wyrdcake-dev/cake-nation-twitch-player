CAKE NATION TWITCH FLOATING PLAYER

1. Host index.html on a public HTTPS static host.
2. Replace YOUR-HOST-DOMAIN in index.html with the exact hostname used to host the file.
3. Test the hosted page directly first.
4. In Google Sites use Insert > Embed > By URL and paste the hosted page URL.

IMPORTANT: Google Sites embeds external pages inside an iframe. The widget can float inside its own hosted page, but Google Sites does not allow the embedded widget to escape its iframe and become a true browser-corner overlay across the whole Google Sites page.

The Twitch player requires the hosting domain in its parent parameter and a minimum player size of 400x300.
